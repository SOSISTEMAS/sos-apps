# SOS Apps — pacote de instalação (links diretos)

APKs curados pela [SOSistemas](https://github.com/SOSISTEMAS) para instalação em
centrais multimídia Android / Android TV / AI Box. Abra o link no Chrome do
aparelho, baixe e toque para instalar (autorize "fonte desconhecida" se pedido).

Todos os apps deste pacote são open source e são redistribuídos sem alteração,
conforme suas licenças. O código-fonte de cada um está disponível nos
repositórios oficiais (links abaixo) — esta redistribuição acompanha essa
oferta de fonte.

| App | O que é | Fonte oficial | Licença |
|---|---|---|---|
| SmartTube | YouTube sem anúncio p/ TV | github.com/yuliskov/SmartTube | MIT |
| Kodi 21.3 | Media center completo | mirrors.kodi.tv / github.com/xbmc/xbmc | GPL-2.0 |
| VLC 3.7.1 | Player universal (pendrive etc.) | videolan.org / code.videolan.org | GPL-2.0+ |
| Aurora Store 4.8.4 | Cliente open source da Play Store | gitlab.com/AuroraOSS/AuroraStore | GPL-3.0 |
| F-Droid | Loja de apps open source | f-droid.org | GPL-3.0 |

O player IPTV da marca SOS (SOS TV) tem repositório próprio:
**github.com/SOSISTEMAS/sos-tv**

Nenhum destes apps inclui listas de canais, conteúdo ou credenciais.
